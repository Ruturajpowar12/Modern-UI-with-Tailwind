# Digital Clock ⏰

A simple digital clock made using **HTML, Tailwind CSS CDN, and JavaScript**.

## Screenshot

![Digital Clock Screenshot](./Screenshot%202026-08-14%20225943.png)

## Technologies

- HTML
- Tailwind CSS
- JavaScript

## Features

- Shows current hours, minutes, and seconds
- Updates every second
- Simple responsive design

## How to Run

Open `index.html` in your browser.
